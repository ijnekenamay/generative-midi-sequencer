# Generative Techno MIDI Sequencer

## プロジェクト概要 (Overview)
本プロジェクトは、Raspberry Pi Pico (RP2040) のデュアルコアアーキテクチャを活かした、ハードウェア動作の **4チャンネル・ジェネレーティヴMIDIシーケンサー** です。
ユーロラックの定番モジュール「Turing Machine」にインスパイアされた確率的シフトレジスタ（S&Hエミュレーション）と、Bjorklundアルゴリズムによるユークリッドリズム生成を組み合わせ、偶発的かつ極めて音楽的なテクノ・ミニマル系のシーケンスを自律的に生成します。

本システムは、余った **「Pico Tracker」ハードウェア（3.2インチ ILI9341 液晶画面、9つの Kailh Choc V1 キースイッチ、PCM5102 I2S DAC搭載）** を流用する形でファームウェアが最適化されており、人間工学に基づいた高コントラストのモノクロームUIからリアルタイムに操作可能です。

## 🛠 実装済みのコア機能仕様 (Current Implementation Specs)

### 1. 4ch 独立 MIDIシーケンサー & クロック同期
*   **4つの完全独立トラック**: 全トラックが独立したシーケンスエンジン（`Track 1`〜`Track 4`）として動作します。
*   **トラック独立のクロック・ディバイド（倍率設定）**: 
    マスタークロックに対して、各トラックごとに個別の倍率（`x1`, `x2`, `x3`, `x4`, `x6`, `x8`, `/2`, `/3` など）をグリッドから選択・設定可能。ポリリズム構築に極めて強力な威力を発揮します。
*   **ステップ長の個別設定 (LEN)**: 各チャンネルごとにシーケンスの長さを `1`〜`32` ステップの間でリアルタイムに変更可能です。
*   **標準 MIDI クロック送信**: UART0 (GP0 TX) を経由して、31,250 bps の標準シリアル MIDI 信号を出力（MIDI Start / Stop / Clock同期に対応）。

### 2. ジェネレーティヴ・リズム & ピッチ生成エンジン
*   **ユークリッド・リズムジェネレータ (`EuclideanGenerator`)**:
    Bresenhamアルゴリズムを応用した軽量かつリアルタイムに計算可能なユークリッドパターン生成。ステップ数 (Length)、パルス数 (Density)、開始シフト (Shift) の3パラメータで制御します。
*   **確率的シフトレジスタピッチジェネレータ (`NoteGenerator`)**:
    16-bitシフトレジスタ（初期値 `0x9E37`）を内蔵。**Mutation（変異確率）** パラメータにより、レジスタのビットがそのままループするか、ハードウェア乱数（Picoの `get_rand_32()`）によって変異するかを 0〜100% の確率で無段階コントロールします。
*   **高精度スケール・クォンタイザー**:
    生成されたランダムなCV値を、選択したスケールおよびルート音（Root Note）に量子化。以下の5つのスケールを瞬時に切り替え可能です。
    1.  **Chromatic (半音階)**
    2.  **Natural Minor (ナチュラル・マイナー)**
    3.  **Phrygian (フリジアン - ダークなアシッド向け)**
    4.  **Dorian (ドリアン - ディープ・テクノ向け)**
    5.  **Minor Pentatonic (マイナー・ペンタトニック - 定番ブルーノート)**

### 3. アナログ・クロック同期出力 (I2S DAC経由)
モジュラーシンセ（Eurorack）やKORG Volcaなどの外部アナログ機器と完全に同期演奏させるため、**音声用 I2S DAC (GP26 Data, GP21 BCLK, GP22 LRCK) から、マスタークロックと100%同期したアナログクロック（ゲート/トリガーパルス）を出力**します。
*   **実装方式**: PIO (Programmable I/O) によるステレオ 16-bit I2S ドライバーと、22.05 kHz バックグラウンドタイマー割り込みを駆使した低遅延出力。
*   **パルス波形**: クロックが進行する度に、左右チャンネルに **5.0ms 幅の最大振幅 (+3.3V) の矩形波トリガーパルス** を正確に生成・出力します。

### 4. 人間工学に基づく極細モノクローム・UI
Ableton PushやElektronなどの最高峰の電子楽器を参考に、薄暗いライブ環境での視覚疲労を抑え、認知スピードを最大化する **「ハイコントラスト・モノクロームUI」** を実現。
*   **ヘッダーエリア**:
    *   スペース効率を極限まで高めた **「BPM縦書き表示」**。
    *   拍（Beat）と完全に同期して **白黒がネガポジ反転フラッシュ** する巨大なテンポ値表示（16x24ボールドフォント）。
    *   現在のステータスを示すピクセルアートアイコン（再生 ▶ / 停止 ■ / ディスク 💾 / ノート 🎵）。
*   **チャンネル・ストリップ (CH1〜CH4)**:
    *   各チャンネルの発音トリガーヒットに合わせて、クロック倍率テキスト（例: `x4`）が**ネガポジ反転フラッシュ**。
    *   選択中のパラメータは **白背景に黒文字のハイライト表示**（非選択のパラメータはダークグレーの枠線付き）。
    *   **MUTE（消音）時のダークアウト**: `RT` ボタンを押すと即座に該当チャンネルがMuteされ、ラベルが `MUTx` に変わり、行全体がダークグレーに減光（ディセーブル表示）。発音動作もミュートされますが、ステップインジケーター（再生ヘッド）は動き続けるため、同期状態は常に把握できます。

### 5. 安全な内蔵フラッシュ・セーブ機能
SDカードによる突発的な書き込み電圧降下（ブラウンアウト）を防ぐため、Pico内蔵の 16MB QSPI フラッシュメモリの最終セクター（`0xFFF000`）へダイレクトに設定データを保存します。
*   **XIPキャッシュクラッシュ防止**: 書き込み実行時は、Core 0 側から Core 1（再生スレッド）を安全にアイドル状態へ移行させ、割り込みを完全に無効化（`save_and_disable_interrupts()`）した上でフラッシュへ書き出すプロ仕様の安全設計を導入しています。

## 🎛 物理キーマッピング (9-Key Controls)

9個のキースイッチのみで快適かつ高速な操作を行えるよう、修飾キー（Shift）を活用したショートカットシステムを搭載しています。

| 物理キー名 | Pico GPIO | 単体押しの動作 | `LT` (Shift) 同時押しの動作 |
| :--- | :--- | :--- | :--- |
| **UP** | GP5 | カーソルを上のトラックに移動 | - |
| **DOWN** | GP3 | カーソルを下のトラックに移動 | - |
| **LEFT** | GP2 | カーソルを左のパラメータに移動 | - |
| **RIGHT** | GP4 | カーソルを右のパラメータに移動 | - |
| **A** | GP8 | 選択パラメータ値を **+1** 増やす | 選択パラメータ値を **+10** 高速増やす |
| **B** | GP7 | 選択パラメータ値を **-1** 減らす | 選択パラメータ値を **-10** 高速減らす |
| **RT** (Page) | GP6 | **MUTE / UNMUTE (ミュート切替)** | - |
| **PLAY** | GP10 | シーケンスの一時停止／再生再開 | **フラッシュへ現在設定を保存 (SAVE)** |
| **LT** (Shift) | GP9 | modifier（Shiftキー）としてホールド | - |

## 🚀 ビルドと動作確認方法 (Build Instructions)

### 前提条件 (Prerequisites)
1. **Raspberry Pi Pico C/C++ SDK** がホストPCにインストールされ、環境変数 `PICO_SDK_PATH` が適切に設定されていること。
2. `arm-none-eabi-gcc` ツールチェーンおよび `CMake` がインストールされていること。

### ビルド実行手順
プロジェクトルートディレクトリにおいて、以下のコマンドを実行します：

```powershell
# 1. ビルド用ディレクトリの作成
mkdir build
cd build

# 2. CMakeプロジェクトの構成
cmake ..

# 3. コンパイルの実行
cmake --build . --config Release
```

### 書き込み手順
ビルドに成功すると、`build/src/` ディレクトリ内に以下のコンパイル成果品が生成されます：
*   **`generative_midi_sequencer.uf2`**: **実機書き込み用バイナリ**

Pico を **BOOTSELモード**（PicoのBOOTSELボタンを押しながらPCとUSB接続）で接続し、PCに認識された仮想ドライブ（`RPI-RP2`）に `generative_midi_sequencer.uf2` ファイルをドラッグ＆ドロップしてください。自動的に書き込まれ、シーケンサーが起動します。
